# Linked lists

These examples use linked nodes to store and move through information.

- [account-transaction-records.cpp](account-transaction-records.cpp) stores accounts and transaction records in linked lists.
- [song-playlist.cpp](song-playlist.cpp) uses a doubly linked list to move between songs.
- [browser-history.cpp](browser-history.cpp) moves forward and backward through a list of website names.
- [singly-linked-list.py](singly-linked-list.py) adds, inserts, deletes, and displays values in a singly linked list.
