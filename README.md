## Run a program

For a C++ example, compile one file from the repository root. Quote the path if it contains spaces:

```bash
g++ -std=c++17 "01-binary-search-trees/inorder-traversal.cpp" -o /tmp/tree-example
/tmp/tree-example
```

Run the Python linked-list example with `python3 03-linked-lists/singly-linked-list.py`.
